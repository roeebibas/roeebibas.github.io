# Roee Bibas - Portfolio

Personal portfolio of Roee Bibas, Art Director and multidisciplinary designer.

The site is built with Next.js and exported as a static website for GitHub Pages.

## Local development

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
```

The static site is generated in `out/`. Every push to `main` deploys it through GitHub Actions.
